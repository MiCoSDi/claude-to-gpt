# claude-to-gpt — архитектура и поведение приложения (русский)

## Назначение

Приложение для локальной подготовки экспорта Claude к ручному использованию в ChatGPT. Оно не создаёт старые диалоги в истории ChatGPT, не входит в аккаунт, не читает cookies браузера и не загружает данные в ChatGPT.

## Обработка

1. Пользователь выбирает ZIP-архивы, JSON-манифест либо оба источника.
2. Для ссылок манифеста приложение показывает подтверждение и открывает проверенные HTTPS-ссылки `claude.ai` по одной в браузере. Пользователь должен быть авторизован и подтвердить завершение загрузки каждого архива.
3. Программа ищет архивы в `Downloads` и рядом с манифестом; если не находит, предлагает выбрать их вручную.
4. ZIP/JSON обрабатываются локально средствами стандартной библиотеки Python. Исходные архивы не изменяются.
5. Результат создаётся в новой папке `claude-to-gpt Export`, не перезаписывая прошлый результат.

## Выходная структура

- `chats/` — отдельные Markdown-беседы.
- `projects/` — описания проектов, исходные JSON и документы.
- `memory/` — экспортированные файлы памяти.
- `artifacts/` — страницы, HTML и ресурсы артефактов.
- `source_data/` — исходные JSON для проверки.
- `upload_to_chatgpt/` — Markdown-пакеты для ручной загрузки.
- `REPORT.md` и, при использовании манифеста, `MANIFEST.md`.

## Фильтр пустых бесед

Необязательный фильтр пропускает создание Markdown только если у беседы нет непустой сводки и читаемого текста сообщений. Он ничего не удаляет: исходный JSON остаётся в `source_data/`, ZIP и файлы пользователя не меняются. Заголовок, ID, дата и ссылка на отсутствующее вложение не считаются содержанием.

## Ограничения и безопасность

- Проверяются пути в ZIP, символические ссылки и предельный размер распаковки.
- URL не записываются в отчёты; ссылки открываются только после согласия пользователя.
- Обратная связь и история входов выключены по умолчанию, так как могут содержать личные сведения.
- Если бинарного вложения нет в экспортных данных, восстановить его нельзя.
- Неизвестные блоки сохраняются в исходном JSON и не выдаются за обычные реплики.

## Требования

Windows и Python 3.10+. Лаунчер проверяет Tkinter и, если Tcl не читает скрипты из пути профиля с кириллицей, спрашивает разрешение скопировать системные скрипты в ASCII-путь и задаёт `TCL_LIBRARY`/`TK_LIBRARY` только для процесса приложения. Сторонние Python-пакеты не нужны.
