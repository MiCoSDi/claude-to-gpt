# Подробная инструкция claude-to-gpt (русский)

## Что делает приложение

claude-to-gpt локально читает экспорт Claude и готовит читаемые Markdown-файлы, документы проектов, память и артефакты для ручного продолжения работы в ChatGPT. Оно не создаёт старые беседы в истории ChatGPT, не входит в аккаунты, не читает cookies и не отправляет результат через сеть. Исходные ZIP не меняются. Все автоматически задаваемые имена папок и файлов приложения — на английском; содержательные названия внутри экспортных данных сохраняются, когда это нужно.

## 1. Что взять и откуда

### Способ A — JSON-манифест Claude

1. Запросите экспорт данных в Claude и дождитесь уведомления/письма со ссылкой, если сервис его отправляет.
2. Скачайте JSON-манифест и сохраните его на компьютере.
3. Войдите в Claude в браузере по умолчанию. Ссылки могут быть временными и иногда одноразовыми.
4. В claude-to-gpt включите **JSON manifest** и выберите файл `.json`.
5. Нажмите **Начать обработку**. Приложение покажет число ссылок и спросит согласие, прежде чем открывать их по одной в браузере. Дождитесь завершения каждого скачивания и только затем подтверждайте переход к следующей ссылке.
6. Приложение ищет ZIP в `Downloads` и рядом с манифестом. Если архив не найден, укажите его вручную в диалоге выбора.

Манифест обычно содержит категории, имена ZIP и временные ссылки, но не сами беседы. Для обработки необходимы ZIP-архивы.

### Способ B — уже скачанные ZIP

Если архивы уже на компьютере, включите **Cloud Memory ZIP** и выберите один или несколько ZIP. Это название источника означает локальные экспортные архивы; внутри могут быть беседы, проекты, память, артефакты и другие данные. Допустимо выбрать только ZIP, только манифест или оба источника. Не распаковывайте ZIP вручную.

## 2. Запуск и работа с окном

1. Скачайте/клонируйте репозиторий.
2. В Windows запустите `Run_claude-to-gpt.cmd` двойным щелчком. Нужны Python 3.10+ и рабочий Tkinter; сторонние пакеты не требуются.
3. Лаунчер проверит Python и Tkinter. Если Tcl/Tk не может открыть системные файлы из пути профиля Windows с кириллицей (например, из `C:\Users\имя-пользователя`), он спросит разрешение скопировать существующие папки `tcl8.6`, `tk8.6` и `tcl8` в доступную папку с ASCII-путём. Для неё подойдёт, например, `C:\Users\Public\Documents`. Переменные `TCL_LIBRARY` и `TK_LIBRARY` будут заданы только для запущенного приложения; Python не переустанавливается и исходная установка не меняется. Если самого Python нет, лаунчер отдельно спросит разрешение на установку через winget.
4. Вверху выберите **Русский** или **English**.
5. Поставьте галочку у нужного источника, нажмите **Выбрать…** и укажите файлы. Статус рядом показывает `✓ ВКЛЮЧЕНО` или `ВЫКЛЮЧЕНО`.
6. Выберите родительскую папку результата. Программа создаст внутри новую `claude-to-gpt Export` или пронумерованный вариант; существующая папка не перезаписывается.
7. Необязательные категории: **Feedback and reflections** — данные обратной связи; **Metadata and login history** — могут содержать email и IP. Оставляйте их выключенными, если они вам не нужны.
8. При необходимости включите фильтр пустых бесед (подробности ниже).
9. Проверьте сводку найденных архивов и подтвердите обработку.

Окно прокручивается колёсиком или полосой справа. Можно уменьшить окно; минимальный размер снижен, чтобы элементы оставались доступны.

## 3. Фильтр пустых бесед — что именно он делает

Эта опция ничего не удаляет с диска. При включении claude-to-gpt просто не создаёт Markdown-файл беседы, если у неё одновременно нет непустой сводки и нет читаемого текста сообщений. Заголовок, ID, дата и ссылки на вложения не считаются содержимым. Запись, где остались только ID и ссылка на отсутствующий PDF, поэтому не попадёт в `chats/` и пакеты загрузки.

Исходный `conversations.json` всё равно сохраняется в `source_data/`. Входные ZIP, пользовательские файлы и существующие папки не удаляются и не изменяются. `REPORT.md` показывает число пропущенных бесед. Если флажок выключен, сохраняются все записи, в том числе пустые.

Фильтр не пытается оценить смысл текста: любая непустая сводка или реплика сохраняется, даже если она короткая. Это намеренно осторожное правило, чтобы не скрыть полезную переписку.

## 4. Где искать файлы результата

В выбранной папке откройте `claude-to-gpt Export/`:

- `chats/` — отдельные `chat_001.md`, `chat_002.md` и т.д.; название и ID находятся внутри файла.
- `projects/` — `project_001/` и далее: `README.md`, исходный `project.json`, `Documents/document_001.ext`.
- `memory/` — текстовые файлы памяти, структура путей сохранена.
- `artifacts/` — страницы, HTML, JSON и ресурсы артефактов. `page.md` читайте в редакторе; HTML открывайте в браузере.
- `source_data/` — исходные JSON для проверки и повторной обработки. Фильтр пустых бесед их не меняет.
- `upload_to_chatgpt/` — готовые Markdown-пакеты `conversations_01.md`, `memory.md`, `project_*.md` для прикрепления.
- `feedback/`, `metadata/` — появляются только при включённых соответствующих опциях.
- `REPORT.md` — счётчики, предупреждения и количество пропущенных пустых бесед.
- `MANIFEST.md` — список ZIP и категорий из выбранного манифеста.

Чтобы продолжить работу, откройте новый чат/проект ChatGPT и прикрепите нужные файлы из `upload_to_chatgpt/`. Например, попросите: «Суммируй решения, сохрани открытые задачи и продолжи с последнего статуса». Приложение ничего не загружает в ChatGPT самостоятельно.

## 5. Частые ситуации

- **Беседа только с ID.** Проверьте `source_data/` и исходный ZIP. Если исходный JSON не содержит сводки или текста, смысл переписки восстановить невозможно. При включённой очистке Markdown не создаётся, но исходная запись остаётся.
- **В чате указан файл, но нет PDF/изображения.** Экспорт сохранил только ссылку/ID вложения. Найдите оригинал в Claude или на компьютере и приложите его отдельно.
- **Ссылка манифеста не скачивает ZIP.** Проверьте вход в Claude, срок действия ссылки и папку загрузки. Для истёкших ссылок запросите свежий экспорт; уже скачанные ZIP можно выбрать вручную.
- **Не хватает проекта или памяти.** Смотрите `MANIFEST.md`, выбранные архивы и предупреждения `REPORT.md`. Повторная обработка создаёт новую папку, прежнюю не перезаписывает.
- **Не видно нижних элементов окна.** Прокрутите колесом или полосой справа.
- **Лаунчер сообщает, что не найден init.tcl.** Это может происходить, если Tcl/Tk расположен в Windows-профиле с кириллицей. Запустите `Run_claude-to-gpt.cmd` и согласитесь скопировать файлы Tcl/Tk в путь только из ASCII-символов; можно выбрать `C:\Users\Public\Documents`. Лаунчер задаст Tcl-пути только для процесса приложения. Запуск командой `python claude-to-gpt.py` может не использовать это исправление — запускайте через лаунчер.

## 6. Ограничения

Обработчик рассчитан на структуру экспорта Claude. Отсутствующие бинарные вложения он восстановить не может. Некоторые сложные артефакты экспортируются как HTML и сопутствующие файлы, не как готовые PDF. claude-to-gpt подготавливает данные для нового чата, но не создаёт старые диалоги в боковой панели и не записывает память в настройки аккаунта ChatGPT. Перед загрузкой просматривайте личные данные.
