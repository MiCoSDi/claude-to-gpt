# claude-to-gpt

**Локальное приложение, которое готовит экспорт Claude для ручного использования в ChatGPT.**

Программа обрабатывает ZIP и JSON-манифест на компьютере, раскладывает беседы, документы проектов, память и артефакты, а затем создаёт Markdown-пакеты. Она не входит в аккаунты, не читает cookies и не загружает файлы в ChatGPT.

## Быстрый запуск в Windows

1. Установите Python 3.10+ с Tcl/Tk или используйте лаунчер.
2. Запустите `Run_claude-to-gpt.cmd`. Если Python/Tkinter отсутствует, программа сначала спросит разрешение на установку. Сторонние библиотеки не нужны. Если Tcl/Tk не может прочитать системные файлы из пути профиля с кириллицей, лаунчер спросит разрешение скопировать только эти файлы в папку с ASCII-путём; установка Python не требуется.
3. Выберите Cloud Memory ZIP, JSON-манифест или оба варианта. Укажите папку результата и нажмите **Start processing**.
4. Итог появится в новой папке `claude-to-gpt Export`; сводка — в `REPORT.md`, Markdown-пакеты — в `upload_to_chatgpt/`.

## Важно

Фильтр пустых бесед только пропускает создание Markdown без текста; исходный JSON и ZIP не удаляются. Если бинарного вложения нет в экспорте, приложение не сможет его восстановить. Старые беседы не появятся автоматически в списке чатов ChatGPT — подготовленные файлы можно прикрепить к новому чату или проекту. Перед публикацией репозитория не добавляйте личные манифесты, ZIP-архивы и папки результатов.
